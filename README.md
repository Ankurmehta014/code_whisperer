# HeartBeatz Music Web App

## Project Structure

```
assets/
  images/    # All image files (.jpg, .png, etc.)
  audio/     # All audio files (.mp3)
css/
  styles.css # Main stylesheet
  login.css  # Login page stylesheet
js/
  scripts.js # Main JavaScript file
pages/
  index.html # Main app page
  login.html # Login page
```

## How to Run

1. Open `pages/login.html` or `pages/index.html` in your browser.
2. Make sure all file references are relative to the new structure.

## Features
- Music player with playlists, new releases, and top charts
- Responsive sidebar navigation
- Login page
- Modular and maintainable folder structure
